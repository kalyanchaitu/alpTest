# AI Bias Audit Dashboard — HR Hiring Decisions

A Streamlit dashboard that audits AI-assisted hiring decisions for demographic bias. It computes fairness metrics by group, visualises disparities, and generates a remediation report.

## What it does

- **Fairness metrics** for each demographic dimension (up to three):
  - Selection rate and **impact ratio** (four-fifths rule, adjustable threshold)
  - **Demographic parity difference**: the gap between the highest and lowest selection rates
  - **Equalised odds difference**: the largest gap in true or false positive rates (needs a `qualified` column)
- **Visualisations**: an impact-ratio heatmap, selection-rate charts with a four-fifths reference line, and TPR/FPR charts
- **Remediation report**: findings ranked High, Medium or Low, with concrete process actions; downloadable as Markdown, with metrics as CSV

Out of scope: model retraining. Recommendations target screening criteria, human review and governance.

## Data format

| column | required | meaning |
|---|---|---|
| `decision` | yes | 1 = AI recommended / selected, 0 = not |
| `qualified` | no | 1 = candidate was actually suitable (ground truth); enables equalised odds |
| demographic columns | 1–3 | e.g. `gender`, `ethnicity`, `age_band`, each with 2–12 distinct values |

`data/sample_hiring_decisions.csv` is a synthetic dataset of 1,200 applicants with bias deliberately injected (against women, non-binary applicants, Group C and applicants aged 45+). It is regenerated by `audit.generate_sample()`.

**Do not commit real employee data to this repository.**

## Run locally

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud

1. Push this folder to a GitHub repository.
2. Go to [share.streamlit.io](https://share.streamlit.io), sign in with GitHub and click **Create app**.
3. Pick the repository and branch, set the main file to `app.py`, and deploy.

## Project structure

```
app.py                      Streamlit UI
audit.py                    Metrics, recommendations and report (pandas only, reusable)

requirements.txt

```

## Method notes

- The reference group in each dimension is the group with the highest selection rate.
- Groups with fewer than 30 records are shown but excluded from summary figures, since their ratios are unreliable.
- The four-fifths rule is a screening heuristic, not a legal test. Treat flagged results as prompts for investigation and review them with legal or compliance colleagues.
