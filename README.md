# AI Bias Audit Dashboard — Performance Ratings

A Streamlit dashboard that audits AI-assisted performance ratings for demographic bias. It computes fairness metrics by group, visualises disparities, and generates a remediation report.

## What it does

- **Favourable outcome**: a *high rating*, meaning a rating at or above an adjustable cut-off (default 4 on a 1–5 scale), because high ratings drive pay rises, bonuses and promotion.
- **Fairness metrics** for each demographic dimension (up to three):
  - High-rating rate and **impact ratio** (four-fifths rule, adjustable threshold)
  - **Demographic parity difference**: the gap between the highest and lowest high-rating rates
  - **Equalised odds difference**: the largest gap in true positive rate (met objectives, rated high) or false positive rate (missed objectives, rated high). Needs a `met_objectives` column
  - **Average rating gap**: the gap in mean rating between groups, in scale points
- **Visualisations**: an impact-ratio heatmap, high-rating rate charts with a four-fifths reference line, rating distributions by group, and TPR/FPR charts
- **Remediation report**: findings ranked High, Medium or Low, with concrete process actions (calibration reviews, proxy audits, rubric fixes, governance). Downloadable as Markdown, with metrics as CSV

Out of scope: model retraining. Recommendations target rating criteria, calibration, human review and governance.

## Data format

| column | required | meaning |
|---|---|---|
| `rating` | yes | AI-suggested rating on a numeric scale (e.g. 1–5), or binary (1 = high rating, 0 = not). Also accepted: `ai_rating`, `performance_rating` |
| `met_objectives` | no | 1 = employee met or exceeded their objective targets (ground truth), enables equalised odds. Also accepted: `kpi_met`, `goals_met`, `high_performer` |
| demographic columns | 1–3 | e.g. `gender`, `ethnicity`, `age_band`, each with 2–12 distinct values |

`data/sample_performance_ratings.csv` is a synthetic annual-review dataset of 1,500 employees rated 1–5, with bias deliberately injected (ratings marked down for women, non-binary employees, Group C and employees aged 45+, and lenient ratings for men who missed objectives). It is regenerated by `audit.generate_sample()`.

**Do not commit real employee data to this repository.**

## Run locally

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Run the tests with `pip install pytest && pytest`.

## Deploy on Streamlit Community Cloud

1. Push this folder to a GitHub repository.
2. Go to [share.streamlit.io](https://share.streamlit.io), sign in with GitHub and click **Create app**.
3. Pick the repository and branch, set the main file to `app.py`, and deploy.

## Method notes

- The reference group in each dimension is the group with the highest high-rating rate.
- Groups with fewer than 30 records are shown but excluded from summary figures, since their ratios are unreliable.
- `met_objectives` should come from objective results (targets, output, quality), not from the same manager judgement the AI learned from, or equalised odds will inherit the same bias.
- The four-fifths rule is a screening heuristic, not a legal test. Treat flagged results as prompts for investigation and review them with legal or compliance colleagues.
